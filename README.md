## How to Run

### IntelliJ IDEA

Open the project in IntelliJ IDEA and run `Main.java`.

### Terminal

Compile the program:

```bash
javac -d out src/Expense.java src/Main.java 
```

Run the program:

```bash
java -cp out Main
```
