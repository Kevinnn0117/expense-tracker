# Learning Notes

- I learned the difference between Git and GitHub. Git manages versions locally and act like a savepoint; GitHub stores and shares the repository remotely.
- I was initially confused about the difference between commit and push. A commit saves a local snapshot, while push uploads commits to GitHub. It's like taking a photo and uploading to instagram.
- I ran into a GitHub Personal Access Token permission issue that caused a 403 error. I fixed it by giving the token the correct repository write permission.
- I learned the difference between an array and an ArrayList. Arrays have a fixed size and ArrayList can grow as new items are added like a python list.
- I learned that a class is a like a blueprint. An object is an instance created from that class.
- I understood why fields (amount, description, category) are private and accessed through getters.
- I learned how ExpenseManager separates expense management logic from Main, instead of putting everything in one class, this way is more clear and Main have less things to handle.
- I learned how to do validation, rejecting an invalid expense before it is added to the ArrayList.
- I learned that javac compiles Java source files and java runs the compiled program.
- I learned how Scanner can read user input from the console and turn that input into a new Expense object. Also it needs to be closed when finish using.
